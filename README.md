# AI Image Generator - MERN Stack

A full-stack AI-powered image generator built with the MERN Stack (MongoDB, Express.js, React.js, Node.js) that transforms text prompts into stunning AI-generated images. This application features a modern, community-driven platform for sharing and discovering creative AI art.

## Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- npm or yarn
- MongoDB instance (local or cloud)
- API key for AI image generation service (e.g., OpenAI)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Afzalshaikh78/ImageGenerator.git
   cd ImageGenerator
   ```

2. **Install server dependencies:**
   ```bash
   cd server
   npm install
   ```

3. **Install client dependencies:**
   ```bash
   cd ../client
   npm install
   ```

4. **Configure environment variables:**
   - Copy `.env.example` to `.env` in both `client/` and `server/` directories (if available).
   - Set your MongoDB URI and AI API keys as needed.

### Running the Application

- **Start the backend:**
  ```bash
  cd server
  npm start
  ```

- **Start the frontend:**
  ```bash
  cd ../client
  npm run dev
  ```

- The client will typically run on `http://localhost:5173` and the server on `http://localhost:5000` (default).

## Environment Variables

You will need to specify the following variables (examples):

**server/.env**
```
MONGO_URI=your_mongodb_connection_string
AI_API_KEY=your_ai_service_api_key
PORT=5000
```

**client/.env**
```
VITE_API_URL=http://localhost:5000
```
